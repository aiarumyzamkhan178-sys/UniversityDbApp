UNIVERSITYDBAPP — ИНСТРУКЦИЯ ПО ЗАПУСКУ

Требования:
- Visual Studio 2022 с поддержкой ASP.NET и .NET 10 SDK
- SQL Server LocalDB (обычно устанавливается вместе с Visual Studio)

Запуск:
1. Распакуйте архив в отдельную папку.
2. Откройте файл UniversityDbApp.slnx в Visual Studio.
3. Дождитесь восстановления NuGet-пакетов.
4. Убедитесь, что в appsettings.json указана ваша строка подключения к SQL Server.
   По умолчанию используется:
   Server=(localdb)\MSSQLLocalDB;Database=UniversityDb;Trusted_Connection=True;MultipleActiveResultSets=true;TrustServerCertificate=True
5. Откройте меню «Сервис → Диспетчер пакетов NuGet → Консоль диспетчера пакетов».
6. В поле «Проект по умолчанию» выберите UniversityDbApp.
7. Выполните команду:
   Update-Database
8. Нажмите Ctrl+Shift+B для сборки.
9. Запустите проект кнопкой запуска Visual Studio.

Возможности:
- Главная панель со статистикой из базы данных.
- Просмотр, поиск, добавление, редактирование и удаление кафедр.
- Просмотр, поиск, фильтрация по кафедре, добавление, редактирование и удаление преподавателей.
- Русскоязычный адаптивный интерфейс для компьютеров и телефонов.

Важно:
Исходная структура базы данных сохранена: Departments и Teachers.
Страницы студентов, предметов и отчётов не добавлялись, поскольку в исходном архиве для них не было моделей и таблиц.
